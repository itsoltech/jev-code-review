Holdout naming checks sample five independently labeled code hunks (PR285/286/287/289); there are **zero labeled positive naming violations**, so holdout precision and recall are **n/a**. The style preset now turns off this failing rule rather than claiming it works.

For readability: 0 very hard to follow, 1 hard or actively misleading, 2 readable with effort, 3 straightforward; label the **whole sampled changed hunk**, not one identifier. ## Recommended composition and limits

`inspect_composition.ts` saved `recommended-composition.json` from the final resolved production loader. Inheritance order is `jev:base` → `jev:security` → `jev:correctness` → `jev:tests` → `jev:recommended`; active rules: 1 base injection guard, 6 security, 4 correctness, 0 tests (**11 total**), no dimensions. `jev:tests` is inherited, but its disabled `tests.missing` rule is omitted from the resolved rules; this composition makes no test-coverage finding. The calibrator's five title rows or seven style rows **do not measure** inherited recommended rules. Their auto/human/disabled decisions, positives, negatives, confirmed FP, positive human/missed and clean human are **n/a here (owned by CoreSafety)**; the 11 active rules inherit their separately measured policy rather than counts invented here. If inherited presets change, re-inspect composition; protection from the active rules remains **contingent on CoreSafety calibration and production health**. The default `blocker` policy and `on_error: neutral` apply. There is no recommendation to auto-approve based on this work.

No test suite, formatter, linter, build or typecheck was run mid-flight. Reproduction above exercised deterministic title checks and live API rule/dimension paths; reading `*.json` permits auditing individual answers, confidence and omissions. Measurements cover historically selected PRs and small curated hunk samples; synthetic source-derived mutations are identified, not misrepresented as natural findings. There is no independent label-agreement study, unbiased candidate-recall estimate, future precision guarantee, or precision claim for zero-prediction/zero-positive rules.
